# Ideas inbox

Unticketed product or process ideas. Agents and humans may append. **Humans** promote to Jira or a GitHub issue, defer, or delete. Do not open a product PR from an inbox note alone.

## File name

`YYYY-MM-DD-short-slug.md`

## Template

```markdown
# <title>

- **Problem:**
- **Why it matters:**
- **Suggested mode/role:** Builder | Sentinel | other
- **Non-goals:**
- **Reporter:** role or non-personal alias only
- **Date:**
```
